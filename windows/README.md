# HTML Studio for Windows

HTML Studio Windows 版是一个面向 Windows 10/11 x64 的 HTML 源码与所见即所得编辑器。

## 功能

- HTML 源码编辑
- 右侧页面直接编辑
- 源码与可视化页面双向同步
- 多文档标签页，可切换和关闭，支持一次打开多个 HTML 文件
- 源码与页面右键菜单：撤销、重做、剪切、复制、富文本粘贴、粘贴为纯文本、删除和全选
- 页面右键菜单可直接修改粗体、斜体、下划线、删除线、段落、列表、文字颜色和背景颜色
- 字体、字号、字形、颜色、段落、对齐、缩进和列表
- 链接、图片和分隔线
- 表格插入、单元格编辑、增删行列和表头切换
- 复制当前页，以及在当前页后新增空白页
- 修改日志持久化、JSON 导出和历史版本恢复
- HTML 打开、保存和草稿恢复
- Markdown 导入与导出
- Microsoft Word `.docx` 导出
- 保留 CSS、背景、表格和分页样式的 A4 PDF 导出，并避免段落或表格行被分页线截断
- 通过 Windows 系统打印对话框打印当前 HTML，并保留背景、表格和分页样式
- 源码、分屏和可视化三种工作区

## 0.3.8 更新

- 普通页面复制/粘贴改为同时读写文本与 HTML，保留字体、字形、颜色、背景、链接和表格等格式。
- 新增“粘贴为纯文本”和 `Ctrl+Shift+V`，可明确移除来源格式。
- 源码编辑区加入完整右键菜单；页面右键菜单加入常用文字格式、段落、列表、文字颜色和背景颜色命令。
- 右键菜单按实际内容和窗口大小定位，并支持滚动，避免功能增加后超出屏幕。

## 0.3.7 更新

- 修复 PDF 导出可能永久停在资源等待阶段、不生成文件的问题。
- 根因是隐藏打印窗口禁用页面 JavaScript 后，`executeJavaScript` 在部分 Electron/Chromium 环境中可能不返回；现改为不依赖页面脚本回调的确定性布局等待。
- 页面加载增加 15 秒超时，PDF 生成增加 45 秒超时，失败时会恢复按钮状态并显示具体阶段。
- PDF 改为先写入临时文件、验证 `%PDF-` 文件头后再替换目标文件，避免失败时留下不完整文件。
- 新增顶部“打印”按钮、文件菜单“打印…”和 `Ctrl+P`，使用同一安全渲染链路打开 Windows 系统打印对话框。
- 新增诊断日志 `%APPDATA%\\HTML Studio\\pdf-export.log`，记录 PDF 导出和打印的加载、完成、取消或错误信息。

## 0.3.5 更新

- 对超长 HTML 进行 PDF 导出核对：Windows 继续使用 Chromium 原生分页打印，不依赖 macOS WebKit 的单张超长画布。
- 打印前强制延迟加载图片转为立即加载，并等待图片、字体和两轮布局完成后再生成 PDF。
- 固定隐藏打印窗口为 A4 比例并禁用后台节流，避免长文档或资源较多时过早进入打印。

## 0.3.4 更新

- PDF 使用 Chromium 原生 A4 排版，并对段落、标题、列表项、图片、表格和表格行增加分页保护。
- 保留网页已有的强制分页规则；能在一页内放下的内容会整体移到下一页。
- Mac 与 Windows 使用新的统一应用图标：代码编辑、页面预览与插入光标合并为一个简洁符号。

## 0.3.3 更新

- 顶部和文件菜单增加“导出 PDF”，快捷键为 `Ctrl+Alt+P`。
- Chromium 按 A4 输出当前 HTML，保留 CSS、背景色、表格和分页规则。
- 导出时禁用页面脚本，并支持原 HTML 所在目录中的相对图片和样式资源。

## 0.3.2 更新

- 顶部新增带文字的“撤销”和“重做”按钮。
- 按钮会识别最后获得焦点的源码编辑器或可视化页面，并在对应区域执行操作。
- 编辑菜单、`Ctrl+Z`、`Ctrl+Shift+Z` 和 `Ctrl+Y` 使用同一套焦点感知命令。
- 可视化工具栏的撤销/重做由符号按钮改为带文字按钮。

## 0.3.1 更新

- 打开软件后自动显示“使用说明”初始标签页；该页可关闭，并可通过“帮助 → 使用说明”重新打开。
- 使用说明是只读内置页，不写入用户草稿、文件或修改历史。
- 同步 Mac 0.3.1 的中文输入法修复：拼音候选合成期间不回写 HTML、不重建选区，确认候选后再同步和记录日志。
- 可视化编辑器仅在状态确实变化时更新 `contenteditable`，避免输入法候选被意外提交。

## 0.3.0 更新

- 修复可视化页面剪切文字后焦点失效、无法继续编辑的问题。
- 修复存在未保存标签时退出命令可能被静默拦截的问题。
- 编辑页面时不再反复重载预览 iframe，光标和选区保持稳定。
- 每个标签页独立保存 HTML、文件路径、未保存状态、选区与修改历史。
- 修改日志最多保留每个文档最近 120 条完整快照，并存放于应用用户数据目录。

## 安全设计

应用使用 Electron 的 `contextIsolation`、渲染器沙箱和精简 IPC 白名单。用户 HTML 在禁用脚本执行的沙箱 iframe 中进行可视化编辑，避免本地 HTML 脚本访问桌面文件能力。

## 开发运行

```powershell
npm install
npm start
```

## 构建 Windows 安装包

```powershell
npm run dist:win
```

输出位于 `dist`：

- NSIS 安装程序
- 免安装 Portable 程序

在无法联网下载 electron-builder 自解压工具时，可基于已有 `win-unpacked` 生成带新版本、图标和 ASAR 的标准便携目录：

```powershell
npm run portable:folder
```
