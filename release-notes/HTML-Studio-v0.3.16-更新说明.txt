HTML Studio v0.3.16 更新说明
发布日期：2026年11月4日

一、发布文件

1. HTML-Studio-macOS-arm64-0.3.16.zip
   适用于 Apple 芯片 Mac；解压后得到“HTML Studio.app”。

2. HTML-Studio-0.3.16-x64-Portable.zip
   适用于 Windows 10/11 x64，完整解压后运行“HTML Studio.exe”，无需安装。

3. HTML Studio-0.3.16-x64-Portable（文件夹）
   Windows 免安装版的已解压副本。

4. HTML-Studio-0.3.16-SHA256SUMS.txt
   两个发布压缩包的 SHA-256 完整性校验值。

二、性能改进

1. 修复大型 HTML（几十页至接近一百页内容）在可视化输入时出现数秒迟滞的问题。
2. 页面编辑期间仅发送轻量“已修改”状态；用户停止输入后，根据页面规模以 350、700 或 1200 毫秒延迟合并一次完整 HTML 快照。
3. 保存、另存为、关闭、切换标签、导出和打印前强制同步最后修改，避免防抖期间遗漏内容。
4. 源码高亮、预览重载、大纲与字数统计、草稿和修改日志改为延迟合并或后台处理。
5. 修改历史按文档体积自动控制快照数量，避免大型文档长期累积过多完整副本。

三、颜色与荧光笔

1. 文字颜色、页面底色和表格底色使用三个独立状态，不再互相联动或自动重置。
2. 初始色板只显示常用标准色及用户保存的自定义色；“更多颜色”按需打开完整系统色板。
3. 点选颜色后立即应用并保持色板打开，方便连续比较；点击“完成”关闭。
4. 新增六色荧光笔：淡黄、浅绿、淡紫、品红、浅蓝、淡橙，默认淡黄。
5. 通过荧光笔箭头选择颜色或“取消颜色（擦除高亮）”，随后拖动选择文字即可涂刷；再次点击主按钮结束工具。
6. Windows 版颜色与页面/表格菜单会根据窗口边界自动调整位置，在 980px 宽窗口中也可完整操作。

四、验证情况

Mac：19 项 Swift/WebKit 回归测试全部通过，包括 2,100 段大型文档连续输入、单次合并同步、颜色独立性、六色荧光笔、中文输入、批注、组件、撤销/重做、窗口布局和保存。

Windows：核心、转换、组件、主进程及 PDF/打印测试全部通过；Playwright 在 1480×900 与 980×640 两种窗口尺寸完成大型文档性能、颜色、荧光笔、31 项大纲、12 种组件、批注、保存和草稿恢复回归。

五、安装提示

Mac 压缩包使用本地临时签名，未经 Apple 公证；首次启动如被系统拦截，请在 Finder 中右键应用并选择“打开”。

Windows 版必须完整解压整个文件夹后运行，不能只复制 exe 文件，也不能直接从 ZIP 预览窗口运行。
