HTML Studio v0.3.17 更新说明

本版本在 v0.3.16 大型文档性能、独立颜色工具和六色荧光笔的基础上，增加定时自动保存与完整的关闭保护。

新增功能
1. 自动保存可选择关闭（默认）、每 30 秒、每 1 分钟、每 3 分钟或每 5 分钟。
2. 已保存的 HTML 会定时写回原文件；首次为未命名文档开启自动保存时，会先要求另存为 HTML。
3. 关闭标签页、关闭窗口或退出应用时，会逐个提示保存/另存为、不保存或取消。
4. 开启自动保存后，关闭时优先写回已有路径的文档；未命名或写入失败的文档继续显示保存提示。
5. 自动保存设置会在下次启动时保留，Mac 与 Windows 状态栏均显示当前设置。

验证
- macOS：22 项 Swift/SwiftUI/WebKit 回归测试全部通过。
- Windows：核心、文档转换、组件、主进程关闭握手、PDF/打印及双窗口尺寸 Playwright 界面测试全部通过。

安装提示
- Mac：解压 ZIP 后，将“HTML Studio.app”拖到“应用程序”文件夹；首次启动如被 Gatekeeper 拦截，请在系统设置的“隐私与安全性”中确认打开。
- Windows：解压免安装 ZIP，运行文件夹中的“HTML Studio.exe”。请保持文件夹内容完整。
