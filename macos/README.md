# HTML Studio for macOS

HTML Studio 是一个使用 Swift、SwiftUI、AppKit 与 WebKit 构建的原生 macOS HTML 工作台。它面向需要快速查看、编辑、实时预览、保存和转换 HTML 文件的用户。

## 0.3.9 更新

- 新增统一查找与替换栏，可在当前使用的 HTML 源码或可视化页面中工作。
- 支持上一处、下一处、循环查找、区分大小写、替换当前和全部替换。
- 页面替换只修改文字节点，保留外围 HTML 标签与已有字体、字形、颜色等格式。
- 新增 `⌘F`、`⌥⌘F`、`⌘G` 与 `⇧⌘G`，源码和页面右键菜单也可打开查找功能。

## 0.3.8 更新

- 源码编辑区加入右键菜单，提供撤销、重做、剪切、复制、粘贴、粘贴为纯文本、删除和全选。
- 页面右键菜单加入“粘贴为纯文本”，并新增字形、段落、列表、对齐、文字颜色和背景颜色等常用命令。
- 页面右键颜色菜单提供常用预设颜色和 macOS 原生颜色面板；背景颜色可一键清除。
- 新增 `⇧⌘V`，根据最后使用的源码或页面编辑区粘贴纯文本。

## 0.3.7 更新

- 修复“导出 PDF”和“打印”共同停在渲染阶段、没有生成文件或没有打开系统打印面板的问题。
- 根因是关闭页面 JavaScript 时，WebKit 的异步资源等待回调在部分 macOS 版本中不会返回；现改为不依赖页面脚本回调的确定性布局等待。
- 为页面加载、分页计算和各段 PDF 生成增加明确超时与错误提示，避免界面无限停留在“准备打印”。
- 增加 PDF 渲染诊断日志 `~/Library/Application Support/HTMLStudio/pdf-export.log`，记录页面高度、页数、分段进度和错误，便于后续排查。
- 使用 17 页实际长文档验证 PDF 完整导出，并确认系统打印面板可识别全部 17 页。

## 0.3.6 更新

- Mac 版增加原生“打印…”功能，可通过顶部“打印”按钮、文件菜单或 `⌘P` 打开系统打印对话框。
- 打印复用 0.3.5 的长文档分段 PDF 渲染链路，与“导出 PDF”保持相同的 A4 分页、背景、表格和跨页保护。
- 系统打印面板支持选择打印机、页码范围、份数、双面和 macOS 提供的其他打印选项。

## 0.3.5 更新

- 修复超长 HTML 超过 WebKit 单张 PDF 尺寸上限后，尾部页面被静默截断的问题。
- macOS 改为按最多 8 个 A4 页分段捕获，再按原顺序合并，长文档不再依赖一张超长 PDF 画布。
- 导出前等待字体和图片完成布局，降低网页资源尚未就绪时立即打印造成的内容缺失。

## 当前功能

- HTML 源码编辑与基础语法高亮
- 右侧页面直接点击输入的所见即所得编辑
- 支持在可视化编辑窗口中使用拼音等中文输入法的候选与组合输入
- 源码与可视化页面双向同步
- 顶部“撤销/重做”按钮会根据最后使用的源码或可视化编辑区执行操作
- 在当前源码或可视化页面中查找和替换，支持循环定位与大小写匹配
- 可视化工具栏提供带文字的“撤销/重做”按钮
- Word 式字体、字号、粗体、斜体、下划线、删除线和颜色工具
- 正文、标题、引用、预格式文本等段落样式
- 对齐、缩进、项目符号和编号列表
- 插入链接、图片、分隔线
- 插入 2×2、3×3、4×4 表格
- 表格单元格编辑、增删行列、切换表头、删除表格
- 可在“直接编辑”和“交互预览”之间切换
- 160 ms 防抖源码预览
- 源码、分屏、预览三种工作区
- 多标签页工作区；每个 HTML 文件在独立标签页打开，可直接点击关闭
- 新建、打开、保存与另存为 HTML
- 打开 HTML、Markdown 和 DOCX
- 源码与页面右键菜单：撤销、重做、剪切、复制、粘贴、粘贴为纯文本、删除和全选
- 页面右键菜单还可修改字形、段落、列表、对齐、文字颜色和背景颜色
- 复制当前页并保留原页面格式，或在当前页后插入空白页
- 页面自动识别、页码顺延和目录链接重建
- 本地修改日志、完整 HTML 快照、JSON 导出和历史版本恢复
- 导出 GitHub Flavored Markdown
- 导出 Microsoft Word DOCX
- 导出保留页面 CSS、背景、表格和分页样式的 A4 PDF；分页时自动避开段落、标题、列表项、图片及可容纳的表格，防止文字被截断
- 使用原生 macOS 打印对话框打印当前 HTML，并保持与 PDF 导出一致的 A4 分页
- 使用统一的新应用图标，以代码编辑、页面预览和橙色插入光标表现核心功能
- 本地图片、CSS、脚本的相对路径预览
- 页面标题大纲
- 未保存更改提示与自动恢复草稿
- macOS 文件关联和原生快捷键

## 系统要求

- macOS 13 Ventura 或更高版本
- 当前预构建版本：Apple Silicon Mac
- 源码最低支持 macOS 13；在安装完整 Xcode 的环境中可构建 Intel 或 Universal 版本
- 可选：Pandoc。检测到 Pandoc 时，Markdown/DOCX 转换会自动使用 Pandoc；否则使用内置兼容转换器。打开 DOCX 目前需要 Pandoc。

## 构建

在终端中运行：

```bash
cd "/path/to/HTMLStudio"
chmod +x scripts/build_app.sh
./scripts/build_app.sh
```

生成的应用和安装压缩包位于：

```text
dist/HTML Studio.app
dist/HTML Studio-macOS-arm64-0.3.9.zip
```

也可以直接开发运行：

```bash
swift run HTMLStudio
```

## 快捷键

- `⌘Z`：撤销当前编辑区域的上一步操作
- `⇧⌘Z`：重做当前编辑区域的下一步操作
- `⌘N`：新建
- `⌘O`：打开
- `⌘S`：保存
- `⇧⌘S`：另存为
- `⌥⌘M`：导出 Markdown
- `⌥⌘W`：导出 DOCX
- `⌥⌘P`：导出 PDF
- `⌥⌘H`：查看修改历史
- `⌘F`：查找
- `⌥⌘F`：查找与替换
- `⌘G` / `⇧⌘G`：查找下一个 / 上一个
- `⌘P`：打印当前文档
- `⇧⌘V`：在当前编辑区域粘贴为纯文本

## 可视化编辑

在“分屏”或“预览”工作区中，右侧默认进入“直接编辑”模式：

1. 点击页面中的文字或表格单元格即可输入。
2. 选中文字后使用上方工具栏修改字体、字号、颜色和字形。
3. 使用“段落”菜单切换正文、标题、引用等结构。
4. 使用“表格”菜单插入表格；把光标放入单元格后，可增删当前行列或切换首行为表头。
5. 使用“页面”菜单复制当前页格式，或在当前页后增加空白页。
6. 在页面中右键可使用剪切、复制、粘贴、粘贴为纯文本、撤销、重做，也可修改文字/背景颜色、段落和列表，或直接复制及新增页面。
7. 关闭“直接编辑”开关后，页面恢复为普通交互预览，链接和页面脚本可以正常工作。

可视化修改会立即写回左侧 HTML 源码，并参与保存及 Markdown/DOCX/PDF 导出。

输入中文时，应用会等待输入法候选确认完成后再同步 HTML，避免拼音字母被提前写入页面。

## 修改日志与恢复

HTML Studio 会在本机为每个文档保留最近 120 个完整 HTML 快照，记录修改时间、来源、动作和字符变化。点击工具栏“修改历史”可以预览、恢复或导出 JSON 日志。恢复动作自身也会生成一条新记录，因此可继续追溯。

日志与自动草稿默认存放在：

```text
~/Library/Application Support/HTMLStudio/
```

## 产品路线

当前版本已经具备基础所见即所得、多标签页、分页复制与可恢复修改日志能力。后续适合按优先级加入：DOM 元素检查与双向选中、属性/CSS 面板、拖拽组件、表格单元格合并拆分、项目文件树、设备尺寸预览、FTP/SFTP 发布以及插件机制。
